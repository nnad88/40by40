# 40by40

40 countries by 40. Track where you've been, what's booked, and where you want to go.

**Install on iPhone:** open https://nnad88.github.io/40by40/ in Safari, tap **Share**, then **Add to Home Screen**.
Your list is saved on your phone only.

This folder is generated by `mobile/build-pwa.py` from the app source; don't edit it by hand.
